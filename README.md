# 透環 TOUKAN — Marble Lab

縦画面の3D玉転がし・ステルス迷路PWA。GitHub Pagesなどの静的ホスティングで動作します。サーバー・アカウントは不要です。

Rapier 0.17.3を含む依存ファイルは同梱済みです。Chromiumで物理動作とオフライン起動を検証しています。[実装・検証状況](./IMPLEMENTATION_STATUS.md) を参照してください。

## 起動

Node.js 18以降、Python 3、curlを使用します。

```sh
npm run serve
```

http://localhost:8000 を開いてください。`file://` での直接起動はES Modules / WASM / PWAに対応しません。本番ではHTTPSが必要です。

`vendor/three.min.js`、`vendor/qrcode.min.js`、`vendor/rapier.es.js` は同梱済みで、外部CDNへのアクセスなしで起動します。Rapier compat版にはWASMが埋め込まれています。取得先は `scripts/vendor.mjs` にバージョン固定しています。GitHub Pagesに配置するときは、vendor内のファイルも必ず含めてください。再取得が必要な場合のみ `npm run vendor` を実行します。

## 遊び方

- 開始画面で「ジャイロを有効にして開始」を選びます。ドラッグ／キー操作でも開始できます。開始前は時間が進みません。
- 画面をドラッグ（複数指の重心にも対応）または矢印キーで傾けます。指を離すと水平に戻ります。
- JUMP / SHAKE またはSpaceで段差を越え、敵を約1.4秒よろめかせます。
- ジャイロボタンで傾き・振り操作を許可します。iOSはユーザー操作から許可が必要です。現在の持ち方が基準です。
- 序盤は1個の玉を穴から明るい下層へ運び、すべて赤色マスのゴールへ導きます。
- 紫の磁力ネットはシェイク連打か左右スワイプで脱出できます。大きな音は敵を呼びます。
- オレンジのゲートは周期的に開き、同じ階層の感圧スイッチを踏んでいる間も開きます。
- 赤い視界と壁越しの音に注意。敵は巡回・調査・追跡・スタンを切り替えます。

## 実装内容

- Three.js PBRプラスチック、縞模様のS/M/L玉、Rapier入力60Hz／物理240Hz、透明天井、天板固定の視差表現。
- 多層床、実際に落下する穴、暗闇フロア、玉の局所光、穴から下向きの光、傾きに連動した太陽光。
- 二足ロボット・蜘蛛・ゼリーの3種類。左右優先／ランダム巡回、壁・ゲートで遮られる視界、音の調査。
- Web Audio合成衝突音・転がり音・警報。音は最初の操作後に開始します。
- 自動Canvas録画（対応ブラウザ）、Float32Array座標ログ、直前3秒のNGリプレイと失敗階層カメラ、ゼリー回収演出。最新ログをIndexedDBに保存。
- グリッド編集、境界線の壁、回転、穴・床・ゲート・敵・玉、消去、Undo/Redo、共存拒否と点滅、制限時間、暗闇設定、到達階層までの追加制限。
- URLでステージ共有、PWA転送コピー／ペースト、コピー案内アニメーション。共有データは検証し、HTMLとして挿入しません。
- IndexedDBの最新50件FIFO履歴、お気に入り保護、履歴から再プレイ、最新リプレイ保存。保存不可環境では一時保存モード。
- Service Workerで全依存をキャッシュ。初回オンライン起動後にオフライン利用できます。

## 検証

```sh
npm test
```

Nodeテストは共有データの日本語ラウンドトリップ、座標・重複・共存・ゴール検証、FIFOとお気に入り保護を確認します。ブラウザ統合テストは `tests/browser.cjs` を参照してください（Playwrightが別途必要）。

## 制約・今後の改善

- 60fpsは端末依存です。解像度上限・軽量影・30Hzログで負荷を抑えていますが、iOS/Android実機での性能調整が必要です。
- 透明リブはPBR透過（透過率0.95・屈折率1.5）、PMREMスタジオ環境反射、上下の円形チューブの光沢を使います。外枠は緑色の不透明プラスチックです。床は不透明です。床際の光と影は軽量な近似で、物理的なコースティクス、擦り傷テクスチャ、ポストプロセスの体積光は未実装です。穴の光はSpotLightと軽量の半透明メッシュです。
- 録画は3D Canvasのみ（HTMLのタイマー等は含まれません）。ファイルの受け渡しにはMediaRecorder最終チャンクの確定が必要なため、厳密な「待ち時間0秒」はブラウザAPI上保証できません。対応形式をMP4/WebMから自動選択します。
- 座標ログは30Hz・最大10分のリングバッファです。メニューの「前回のリプレイ」で最新プレイのログ全体を再生できます（ゲーム内の記録に限ります）。
- ステージは圧縮形式のURLとQRで共有します。QRの容量を超える大きなステージはURLコピーを使用してください。共有先サービスのURL長制限に注意してください。
- クリップボードの自動検知は、PWAがフォーカスを得たとき、読み取り権限が既にある場合に限ります。iOS等では「コピー受入」から貼り付けてください。
- 到達階層は端末内のクエスト進行です。ローカルデータ消去で失われます。敵は軽量なグリッドAIであり、動的障害物を含む完全な経路探索ではありません。
- 大玉によるギミック破壊は未実装です。S/M/Lの半径・密度・衝突音の差は反映しています。

依存: Three.js r146 (MIT)、QRCode.js 1.0.0 (MIT)、Rapier3D compat 0.17.3 (Apache-2.0)。各配布元のライセンスが適用されます。

盤面は8×11マス。新規階層は明るい状態で追加され、エディターの「暗闇」で階層ごとに変更できます。ロボットの赤い扇形は視野です。発見されると追跡が始まり、接触すると失敗します。通常の転がり音はなく、壁への衝突音があります。
